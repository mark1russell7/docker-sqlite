          How it works

          1. 1

            SQLite in WebAssembly

            The package uses sql.js, so it needs no native build. This page uses the same sql.js, with its WebAssembly file from this site.

          2. 2

            Migrations in savepoints

            runMigrations applies each pending version in a savepoint, with its row in _migrations. A failure keeps no part of the migration.

          3. 3

            Queries with parameters

            query gives the columns and the rows as objects. execute binds the parameters to one statement, and gives the number of changes.

          4. 4

            Files on Node.js

            withConnection loads the file, runs your code and saves the file only when it changed, with a write to a temporary file and a rename.

          The entry @mark1russell7/docker-sqlite/pure has the queries and the migrations. It imports no Node.js module, so this page bundles it. The log shows the SQL of each call: the page gives the package a database that records each SQL text.

          Docker commands

          The shipped docker-compose.yml starts sqlite-web, a web UI for one database file, on 127.0.0.1:8080. The UI can read and write the file and has no login, so the port opens only on the loopback address.

          Open the database of this page

          mkdir -p data
mv ~/Downloads/playground.db data/cli.db
docker compose up -d
# Open http://localhost:8080

          Other settings

          SQLITE_PORT=8081 SQLITE_DB_PATH=./db SQLITE_DB_NAME=app.db docker compose up -d

          Logs and stop

          docker compose logs -f sqlite-web
docker compose down

          From your project, after the install

          docker compose -f node_modules/@mark1russell7/docker-sqlite/docker-compose.yml up -d

          Install from npm

          npm install @mark1russell7/docker-sqlite
          import { createMigration, execute, query, runMigrations, withConnection } from "@mark1russell7/docker-sqlite";

const migrations = [
  createMigration(1, "Create the users table", "CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT)", "DROP TABLE users"),
];

await withConnection({ dbPath: "./data/app.db" }, (db) => {
  runMigrations(db, migrations);
  execute(db, "INSERT INTO users (name) VALUES (?)", ["Ada"]);
  console.log(query(db, "SELECT * FROM users").rows);
});

          The package needs Node.js 22 or later. The web UI needs Docker with Compose. In a browser, import the same functions from @mark1russell7/docker-sqlite/pure.
